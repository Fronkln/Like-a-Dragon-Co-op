# Like a Dragon Co-op
Co-op for Yakuza 7

# Building
1) Clone the [latest Dragon Engine library source code](https://github.com/Fronkln/Dragon-Engine-.NET)
2) Open the solution, remove the missing DELibrary.NET reference
3) Add your cloned source code to the solution and add it as a reference for the mod
4) You're ready to build (I hate GitHub submodules)
